# First Project — Todo App

A simple client-side Todo app built with plain HTML, CSS and JavaScript.

Features
- Add todos with name, description and priority (high / medium / low).
- Persistent storage using `localStorage`.
- Delete todos and themed toast notifications for save/cancel actions.
- Responsive popup with auto-focus for quick input.

How to run
1. Open `index.html` in your browser (no server required).
2. Click **Add todo**, fill the fields and click **Save**.

Project structure
- `index.html` — main page
- `css/index.css` — styles
- `js/index.js` — application logic
- `images/` — supporting images

Notes & next steps
